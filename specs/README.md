# acLabs engineering specifications

This directory contains engineering contracts for acLabs components. They are
intended for maintainers, contributors, automation, and coding agents. They live
outside the MkDocs documentation tree and are not published to GitHub Pages.

Each component has its own directory. Specifications use numbered documents with
a title, status, date, context, and decisions.
Additional sections can describe interfaces, examples, open questions, and
acceptance criteria.

A document marked **Draft** is a proposal for review. Its normative language
describes the intended contract; it does not imply that every requirement is
accepted or implemented. Accepted documents should be updated alongside changes
to their contracts. Numbers are scoped to each component directory.
